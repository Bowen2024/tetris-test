# Tetris Test

使用 Python 3.12 和 pygame-ce 开发的桌面版俄罗斯方块项目。

## 当前状态

项目处于基线搭建阶段。开发前请先阅读：

- [Coding Agent 开发入口](AGENTS.md)
- [Python 开发框架](docs/DEVELOPMENT_FRAMEWORK.md)

`AGENTS.md` 告诉新 Agent 应该先读什么、当前只做哪一阶段、哪些架构规则不能破坏以及如何验收。框架文档则明确首版范围、项目目录、数据协议、游戏规则、测试清单和分阶段开发顺序。

## 首个开发任务

只完成项目基线：创建目录、配置 `pyproject.toml`、建立最小 pygame 空窗口和 `tetris` 命令入口。暂不实现游戏规则。
