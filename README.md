# Tetris Test

使用 Python 3.12 和 pygame-ce 开发的桌面版俄罗斯方块项目。

## 当前状态

仓库当前提供完整的开发规格，目标是让 Coding Agent 按文档实现并交付整个可玩首版。开发前请先阅读：

- [Coding Agent 开发入口](AGENTS.md)
- [Python 开发框架](docs/DEVELOPMENT_FRAMEWORK.md)

`AGENTS.md` 告诉新 Agent 应该先读什么、怎样连续执行全部阶段、哪些架构规则不能破坏以及如何验收。框架文档则明确首版范围、项目目录、数据协议、游戏规则、测试清单和分阶段开发顺序。

## 开发任务

完成整个俄罗斯方块首版。必须从项目基线开始，按照框架文档中的阶段 1–7 顺序开发；每个阶段通过测试和检查后自动进入下一阶段，直到游戏完整可玩并通过最终验收。阶段拆分用于控制质量，不代表完成阶段 1 后停止。
